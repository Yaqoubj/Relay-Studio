# Relay Studio v1.4.0

Choose a folder and review one organization plan for mixed files. No AI mode groups TV episodes with subtitles, pictures and screenshots, documents, audio, archives, and installers. It can make folders inside the selected location, in a new subfolder, or in another folder. Photos with matching filename families or similar small thumbnails can get a shared folder; unknown files are left out of the selected batch.

With AI mode starts from that local plan and asks your connected model for supported document topics and names. The model receives extracted document text only after provider confirmation. The review groups related proposals so you can include or skip a group, and undo removes folders Relay created when they are empty.

Broader goals include combining source folders into a chosen library, reviewing exact duplicates and large old files in one storage plan, and preparing a delivery with a checksum manifest. Files with private-looking names are unselected from the delivery by default. Saved No AI setups can prepare recurring reviews while the app is open.

Large scans pause between folders, save the pending folder list, and let you review a completed section before continuing. A very large single directory can exceed the section target. Local thumbnail comparison covers at most 500 photos per scan section; AI mode does not understand image subjects.

ChatGPT Plus does not cover general API calls in Relay. AI mode works with a local Ollama model or a separately billed OpenAI-compatible API key.
