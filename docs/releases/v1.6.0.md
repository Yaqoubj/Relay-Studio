# Relay Studio 1.6.0

Relay Studio brings file organization, library search, picture/PDF/text tools, and visual automation into one Windows desktop app.

Choose a personal folder to see collection cards with examples and destinations. Episodes stay with subtitles, photos use capture dates where available, and readable documents can use local content clues. Keep original names, reuse folders, remember filing choices, and undo verified file changes.

Automatic filing handles stable arrivals using remembered choices while Relay is open. Whole-folder moves relocate explicitly selected personal collections intact. Library indexes search filenames and document text, retain offline-drive snapshots, and support saved searches.

The local tools need no account or AI. Optional models use the user's connection. Recognized application/game/code trees and uncertain files are held back; existing destination files are never overwritten.

The source build, 58 unit tests, and 7 Electron end-to-end tests pass. Updated screenshots document synthetic desktop flows. No installer or release has been produced; packaged checks and publication remain with the owner.
