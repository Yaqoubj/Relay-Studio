# Relay Studio 1.0.0

Relay Studio is a Windows desktop app for organizing files, searching a local library, working with pictures, PDFs, and text, and automating repeat tasks.

Choose a personal folder to review grouped files and suggested destinations. Episodes stay with subtitles, photos can use capture dates, and readable documents can use local content clues. Original filenames are kept. Review changes before applying them, then undo verified moves when needed.

Remember filing choices for stable arrivals while Relay is open. Move selected personal collections with their contents intact. Index chosen folders or drives to search filenames and extracted text, even when an external drive is offline.

Everyday tools work without an account or AI connection. Optional AI uses a model connection you provide. Recognized application, game, and code-project trees stay protected, and existing destination files are never overwritten.

The source build, 58 unit tests, and 7 desktop end-to-end tests pass. Installer packaging and publication are the remaining release steps.
