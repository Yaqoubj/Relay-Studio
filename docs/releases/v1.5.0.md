# Relay Studio 1.5.0

Relay now opens as a desktop toolbox. Choose a visible action on Home or drop files into it, then open or locate the result. The first tools make pictures smaller, resize or convert them, create a PDF from pictures, merge PDFs, save selected pages, extract text, and clean pasted text. These actions work locally without an account or AI connection and leave source files in place.

The existing file organizer, saved setups, visual workflows, and optional AI connections remain available under Advanced. Smart organization now preserves filenames by default. File scans and mutations avoid recognized game saves, application folders, and code projects; the review remains necessary for folders containing mixed or unfamiliar data.

Activity shows recent toolbox results. Background job recovery, capture, clipboard history, media tools, and remote execution are still planned.
