# Relay Studio v1.3.0

Scan folders and data drives, choose a template, and review the exact file changes before applying them.

**No AI needed:** drive organization, downloads cleanup, bulk renaming, large/old file review, exact duplicate review, photo capture-date filing, age-based archives, delivery copies with checksums, and backup verification.

**AI powered:** document filing, receipt records, meeting actions, research notes, screenshot filing, project/topic grouping, and filing advice. Use your local model or a cloud provider with your own key. Review generated content and suggested paths before writing anything.

- Saved scans, plans, and per-file operation records.
- Selection, name-conflict detection, cancellation, and verified batch undo.
- Local PDF/DOCX/text extraction and bundled English OCR.
- AI request/text limits, confidence thresholds, allowed categories, and result caching.
- Reusable folder setups and scheduled reviews while Relay is open.
- Updated template library, screenshots, and architecture documentation.

Scheduled reviews do not apply file changes or make unattended AI requests. System/application paths, linked files, dot paths, and recognized projects are skipped. Existing files are never overwritten. Undo stops on changed content or occupied restore paths; uncertain interrupted operations require inspection. Collection records remain local. The Windows installer is unsigned.
